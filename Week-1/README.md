## 🎯 The Journey Begins: Week 1 Focus
Week 1 lays down a strong foundation in algorithmic thinking and core language features. The focus is divided between **Core Java features** (like lambda expressions and custom comparators) and **fundamental array manipulation** techniques. 

### 🌟 Key Concepts Mastered:
- **Prefix Sum Arrays**: Utilized in problems like *Running Sum* and *Find Pivot Index* to optimize repeated range-sum queries from $O(N^2)$ to $O(N)$.
- **Two-Pointer Techniques**: Essential for solving problems like *Squares of a Sorted Array* in optimal time.
- **Java 8+ Features**: Deep dive into Lambda Expressions and the Comparator interface for functional programming and custom sorting logic.
- **Matrix Iteration**: Navigating 2D arrays efficiently as seen in *Richest Customer Wealth*.
